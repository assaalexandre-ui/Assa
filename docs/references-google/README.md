## Ce que ces documents ne sont pas

- Ce ne sont pas des copies intégrales : ce sont des résumés des points à appliquer, avec le lien vers la page complète.
- Les pages évoluent. Vérifier la date de mise à jour indiquée dans chaque fichier avant une décision importante.
- Ils n'ont pas encore été appliqués au code. Les écarts observés dans l'application seront traités dans une étape à part, après validation.
