# Logo EMCV — concept 1 « Lumière »

Lettres géométriques en traits épais ; le C reste ouvert et une croix dorée se loge dans l'ouverture.

| Fichier | Usage |
| --- | --- |
| `logo-emcv.svg` | Fond clair (encre #1B2636, croix or #C48D1D) |
| `logo-emcv-blanc.svg` | Fond sombre ou bleu (blanc, croix or clair #E3B04B) |
| `logo-emcv-bleu.svg` | Variante bleu EMCV #2F86D6 |

Couleurs de l'application : encre #1B2636, bleu #2F86D6, or #C48D1D, vert « Structure de l'église » #158467, ciel #E6F2FC, barre latérale #15253C.
Sous 60 px de large, retirer la croix pour garder la lisibilité. Le canevas source (2 concepts + déclinaisons) est dans `canevas-logo/`.
